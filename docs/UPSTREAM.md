# Source provenance

This experimental Obsolete Coin fork is based on https://github.com/brisvia/brisvia
at commit `59cd3d65e97348cf221662b9cdc27d4834daf7c3`, itself a Bitcoin Core 30.2 fork.
RandomX is pinned by the existing submodule, not downloaded at a floating version.
Original MIT notices and third-party licenses are preserved. Internal `Brisvia`
symbols and the `bitcoind`/`bitcoin-cli` build target names remain for traceability.
They do not identify the selected network. Use the Obsolete launch scripts.
Upstream documentation describes upstream software and is not the Obsolete specification.
Obsolete-specific documentation lives in docs/ and README.md.
